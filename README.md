# AI-Room: AI-Powered Interior Design & Room Styling
An innovative Python-based application concept that leverages Artificial Intelligence and computer Vision to transform interior design and room styling. Users can upload an image of any room and generate high-quality interior designs based on selected themes and preferences.

---

#Features
* **Image Upload:**Seamlessly upload room images (JPG, PNG).
* **Style Selection:** choose from multiple inerior design themes(Modern Minimalist,Bohemian,Scandinavian,Classic Luxury,Industrial).
* **AI Transformation:** Automated image synthesis and room restyling concept.
*  **Interactive UI:** User-friendly interface built with Streamlit.
